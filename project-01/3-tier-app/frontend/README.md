# Frontend

### Requirements

- Node.js 18+

### Setup

```bash
cd frontend
npm install
```

### Run

```bash
npm run dev
```

The app will be available at:

```txt
http://localhost:5173
```

> The backend must be running for the frontend to work.

### Build for production

```bash
npm run build   # output goes to frontend/dist/
npm run preview # preview production build locally
```
